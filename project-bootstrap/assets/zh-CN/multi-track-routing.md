## 工作上下文

- 本项目的多条任务线共享仓库、原始资料和可复用工具。共享约束保留在根目录本文件，各线 `RULES.md` 只保存专属要求。
- 开始任务时读取 `context/ACTIVE.md`，再读取所选任务线的 `RULES.md`、`STATE.md` 和存在时的 `MEMORY.md`；如果根目录 `MEMORY.md` 保留了共享经验，也一并读取。不默认加载全部任务线的上下文。
- 用户明确要求继续或切换某条线时更新全局任务线状态，否则沿用当前任务线。仅查询另一条线已有信息或维护仓库组织，不自动切换。
- `context/ACTIVE.md` 只记录当前任务线及入口，不写阶段进度和切换流水；各线目标/阶段、已完成事实及证据、阻塞和下一步写入 `context/<track-id>/STATE.md`。
- `MEMORY.md` 保存长期决定、理由及可复用经验，附来源或提交引用；有用时再创建。在阶段收尾、方向改变或重复/过时时合并整理，目标约一页。详细历史通过 Git 查询，不维护 `HISTORY.md`。
- 实质工作完成后只更新受影响任务线中有变化的信息。共享成果保留一份，各线按需记录采用的路径、版本和用途；另一条线尚未评估的成果仅作待评估输入，不自动推进完成状态。
- 默认串行工作；如果用户同时运行多个聊天，以各聊天显式指定的任务线为准，避免竞争写入全局状态或同时修改同一文件。
- 只读问答不更新规则、当前任务线、状态、记忆、导航和日期，不创建报告、检查文件或空提交。明确要求切换或记录决定属于状态变更，仅处理指定范围。
